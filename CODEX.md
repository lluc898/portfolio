## 16. SEO

### Dominio y URL canónica

El dominio oficial de producción es:

`https://llucbosch.com`

Toda la configuración de SEO debe utilizar este dominio como URL base. No usar como canónicas URLs temporales de despliegue, dominios de preview, `localhost`, direcciones con `www` ni variantes duplicadas.

Configurar Astro con `site: "https://llucbosch.com"` para poder generar correctamente URLs absolutas, canonical, sitemap y metadatos sociales.

Definir una única estrategia para las URLs —incluido el uso de trailing slash— y aplicarla de manera consistente. Si el hosting expone `www.llucbosch.com`, debe redirigir permanentemente a `https://llucbosch.com`.

Implementar correctamente:

- `<title>`
- meta description
- canonical absoluta basada en `https://llucbosch.com`
- Open Graph con `og:url`, `og:title`, `og:description`, `og:type` y una imagen social absoluta
- Twitter/X cards cuando corresponda
- favicon
- `sitemap.xml` con URLs de producción del dominio oficial
- `robots.txt` que permita indexar el contenido público y declare `Sitemap: https://llucbosch.com/sitemap-index.xml` o la ruta real generada
- datos estructurados Schema.org para `Person`, incluyendo `url: "https://llucbosch.com"` y perfiles públicos confirmados mediante `sameAs`
- atributo `lang` correcto en el documento HTML
- jerarquía de headings coherente, con un único `h1` principal
- URLs absolutas para imágenes y recursos incluidos en metadatos
- página 404 útil que no responda con estado 200
- redirecciones permanentes cuando cambie una URL pública

Título recomendado:

`Lluc Bosch Ramis — Software Engineer`

La descripción debe ser profesional y natural.

Descripción conceptual recomendada:

`Portfolio de Lluc Bosch Ramis, Software Engineer especializado en desarrollo web y en flujos de desarrollo asistidos por IA con Claude CLI, agentes, skills y loops.`

Ajustar el texto final para que sea natural y conciso, sin superar innecesariamente la longitud habitual de una meta description.

No realizar keyword stuffing.

No bloquear mediante `robots.txt` los recursos necesarios para renderizar la página.

No incluir en el sitemap páginas de preview, rutas internas, páginas duplicadas o contenido marcado como `noindex`.

Antes de publicar, comprobar que canonical, Open Graph, JSON-LD, sitemap y robots apuntan exclusivamente a `https://llucbosch.com`.
